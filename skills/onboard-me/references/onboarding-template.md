# ONBOARDING.md template

Use this structure when writing `ONBOARDING.md` at the repo root. Replace every
`{{...}}` with real findings. Omit a section only if it genuinely does not apply
— and when you omit one (e.g. no PR process, no deployment), leave a one-line
note saying so, so the reader knows it was checked and not just forgotten.
